# Corral Website

## 👋 Привет!

Я разрабатываю **Corral** — навигатор по регистрациям и лотереям зарубежных марафонов для русскоязычных бегунов.

Corral помогает не пропустить открытие регистрации, заранее узнать условия участия и перейти к официальному источнику организатора.

🌐 [Открыть сайт](https://corral.website/)  
📋 [Посмотреть историю обновлений](./CHANGELOG.md)

Этот репозиторий содержит публичную историю развития сайта. Исходный код, административные инструменты и детали внутренней инфраструктуры здесь не публикуются.

## 🛠 Стек

- **Интерфейс:** `HTML5`, `CSS3`, `JavaScript`
- **Генерация страниц и API:** `PHP 8.2`
- **Хранение данных:** `MySQL`
- **Веб-сервер:** `Nginx`
- **SEO:** `Schema.org`, `JSON-LD`, `Open Graph`, `sitemap.xml`
- **Тестирование:** автоматические тесты PHP и проверки сгенерированных страниц

Сайт работает без клиентских фреймворков: публичные страницы заранее формируются из актуальных данных Corral и отдаются посетителям как статические документы.

## 🏃 Возможности

### Каталог марафонов

- Публичный каталог международных марафонов.
- Для каждого забега создаётся отдельная постоянная страница.
- В каталоге отображаются страна, город, дата старта и текущий этап регистрации.
- Забеги упорядочиваются так, чтобы открытые регистрации, лотереи и ближайшие дедлайны были заметнее.
- Каталог открывается сразу на главной странице Corral.
- Можно сделать забег «главным», тогда он будет занимать две карточки вместо одной: в этом случае добавляется отображение краткого описания забега.

### Страницы забегов

На странице марафона могут быть указаны:

- дата и место проведения;
- сроки и способ регистрации;
- дата публикации результатов лотереи;
- способ получения слота;
- стоимость участия;
- визовая информация;
- доступные способы оплаты из России;
- официальные источники и страница регистрации.

Если организатор ещё не опубликовал точные даты или условия, Corral показывает, что информация ожидается, и не подставляет предположительные сведения.

### Навигация и оформление

- Адаптивный интерфейс для телефонов, планшетов и компьютеров.
- Поддержка светлой и тёмной темы.
- Страница «О Corral» с описанием сервиса и принципов его работы.
- Отдельная политика конфиденциальности сайта.
- Страница 404 для несуществующих адресов.
- Клавиатурная навигация, контраст текста и совместимость со скринридерами и другими вспомогательными технологиями — по стандартам доступности.

### Поисковая доступность

- Главная страница и страницы забегов доступны для индексации.
- Формируется актуальная карта сайта.
- Используются постоянные canonical-адреса и хлебные крошки.
- Есть структурированные данные о спортивных событиях.
- Ссылки корректно отображаются при публикации в социальных сетях и мессенджерах.
- При изменении адреса забега старая ссылка автоматически ведёт на новую.

### Актуальность и надёжность

- Каталог и страницы забегов формируются из единого источника данных.
- Для информации о забегах установлен срок редакционной перепроверки.
- Неизвестные сведения не заменяются предполагаемыми датами или условиями.
- При ошибке обновления посетителям продолжает показываться последняя успешно опубликованная версия сайта.
- Состояние публикации контролируется отдельно, чтобы ошибки не оставались незамеченными.

### Конфиденциальность и безопасность

- Для просмотра сайта не требуется регистрация.
- Сайт не запрашивает у посетителей имя, email, телефон или другие данные профиля.
- На публичных страницах нет форм, cookies и сторонних систем аналитики.
- Сайт работает по HTTPS.
- Используются ограничения браузерных разрешений, Content Security Policy и другие защитные заголовки.
- Подробнее об обработке технических данных рассказано в [политике конфиденциальности](https://corral.website/privacy.html).
